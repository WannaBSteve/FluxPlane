# 从数据目录到自然语言分析

FluxPlane 的分析工作台将数据选择、查询计划和执行结果放在同一条流程中。自然语言用于描述分析目标，实际查询由 DuckDB 执行；表、文档和已计算特征都可以作为输入。

## 1. 先看数据，再开始分析

进入「数据目录」，左侧按来源分组，右侧展示表和文档。点击任意数据卡片，可以查看：

- **内容预览**：分页查看指定版本。文档默认显示正文片段，也可切换到数据表。
- **字段与分布**：字段类型、空值数量、抽样不同值和可用的分布摘要。
- **数据关系**：数据来源、依赖输入与下游特征，关联节点可以继续点击。
- **版本历史**：选择某一版本，直接查看该版本的内容。

点击「用这份数据分析」，工作台会自动选中它。需要跨表分析时，再从左侧加入其他表或特征。

## 2. 连接分析模型

使用支持 `chat/completions` 和 JSON 输出的 OpenAI 兼容服务。在服务器配置：

```bash
FLUXPLANE_ANALYSIS_BASE_URL=https://your-provider.example/v1
FLUXPLANE_ANALYSIS_MODEL=your-model-name
FLUXPLANE_ANALYSIS_API_KEY=your-provider-key
FLUXPLANE_ANALYSIS_TIMEOUT_SECONDS=60
```

Compose 部署将这些值写入本机 `.env` 后，重建 API 与前端：

```bash
docker compose up -d --build api web
```

本地 Python 启动方式需先 `export` 环境变量，再启动 API。Python 服务不自动加载 `.env`。

密钥只供 API 使用，不发送到浏览器，也不传给 worker。规划请求包含用户问题、所选表的字段及特征定义，不附带数据行。若采用远程模型，这些内容将发送到配置的服务。未连接模型时，界面会显示配置入口，SQL 查询仍可使用。

## 3. 一次可展示的分析流程

运行 `bash scripts/quickstart.sh` 装载演示数据后，可以先在 SQL 模式点击「各品类销售额」「退款后的净额」或「退货相关文档」，直接执行并查看结果。连接模型后，再试一次自然语言分析：

1. 打开 `demo_orders`，查看金额、商品编号和日期字段。
2. 在「数据关系」点击 `demo_customer_net_30d`，查看按客户汇总的特征结果。
3. 进入分析工作台，选择 `demo_orders` 和 `demo_products`，提问「按商品类别统计销售额和订单数」。
4. 检查生成的统计口径、输入版本，以及读取、关联、分组、汇总和排序等操作。
5. 展开 SQL 查看具体实现，点击「确认并执行」。
6. 查看任务状态和结果，切换图表并选择分类列与数值列。
7. 回到数据目录，打开 `demo_policy` 阅读退货说明，再单独分析「查找提到退货期限的段落」。

图表展示当前结果页，不会额外聚合。文档查询基于已接入文本及 SQL 文本匹配，不会自动添加向量检索或语义相关性评分。

## 4. 执行与回看

生成计划不会运行查询。服务先检查引用的表、字段及只读 SQL 是否可用；需要补充口径时，会返回澄清问题。确认执行后，查询进入现有任务队列，结果与该次任务绑定。

如果规划后相关数据已经更新，界面会提示重新生成计划。已经提交的查询则继续读取提交时固定的版本。最近查询保存原问题、SQL 和执行状态，可以点击回看，页面刷新也能恢复上次选中的任务。

操作流程图根据 SQL 结构生成，用于解释计划，不是数据库内部的物理执行顺序或逐算子计时。下方执行进度来自真实任务状态。

## 接口

| 接口 | 用途 |
| --- | --- |
| `GET /api/v1/catalog/datasets/{id}/preview` | 表或文档的分页预览 |
| `GET /api/v1/catalog/features/{id}/preview` | 特征结果的分页预览 |
| `GET /api/v1/analysis/status` | 模型连接配置状态，不包含密钥 |
| `POST /api/v1/analysis/plan` | 生成并验证分析计划 |
| `POST /api/v1/queries` | 执行 SQL，可附带计划中的 `expected_versions` 和原 `question` |

预览接口支持 `offset`、`limit` 和 `version_id`。规划与执行需要管理员或操作员权限，浏览数据也支持只读角色。
