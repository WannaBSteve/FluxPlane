# 交付验收记录

更新：2026-11-10。验收对象为独立的 FluxPlane 原型，按[架构计划第 15–16 节](architecture-plan.md#15-演示与验收)检查。以下区分已直接验证的能力和首版边界。

| 验收方向 | 直接证据 | 结论 |
| --- | --- | --- |
| 独立部署 | 从独立目录启动 Compose；Web、API、调度器、两个执行池与 PostgreSQL 运行；`verify_deployed.py` 检查 Web、健康状态、角色、目录、物化状态和运行指标 | 通过 |
| 多源数据与分析 | [完整演示](../examples/full_demo.py)接入 PostgreSQL、Parquet、HTTP JSON、Markdown/PDF，发布特征并执行跨源 SQL；[部署记录](operations.md#独立启动与服务重建验证)包含更新和重跑 | 通过 |
| 正确性与版本 | [端到端测试](../tests/test_online_workflow.py)覆盖新增、改写、删除对账、迟到与窗口到期、幂等提交、固定输入版本、schema 阻断和原子恢复 | 通过 |
| 调度与恢复 | 同一测试覆盖依赖、优先级、资源准入、取消、租约与过期发布围栏；[故障演示](../examples/worker_recovery_demo.py)验证 worker 退出后的单次可见发布 | 通过 |
| 产物与存储 | `verify-storage` 检查发布产物；[跨实例恢复演练](operations.md#在新目录恢复)验证备份、恢复及查询；测试覆盖孤儿回收与运行中读者保护 | 通过 |
| 前端交互 | 六个页面经过桌面与窄屏浏览器检查；真实实例中完成字段画像查看、SQL 查询、75 行结果翻页、主题和任务状态刷新，移动宽度未出现页面横向溢出 | 通过 |
| 接口与扩展 | FastAPI 提供 OpenAPI；控制台读取类型由响应模型生成，`npm run check:api` 校验；[扩展指南](extensions.md)说明连接器、算子和部署边界 | 通过 |
| 性能与规模 | [性能报告](performance-report.md)保留单机、Compose 混合负载、增量刷新和百万行规模的原始记录；包含控制请求、调度、端到端时间及产物大小 | 已测量，结论限定于报告中的部署和负载 |
| 授权与来源 | 前端组件基于固定的 Shadcn Admin 提交，保留其 [MIT 许可证](../third_party/shadcn-admin/LICENSE)；源码和文档未出现旧项目产品名称 | 通过 |

最新回归：后端 75 项通过、1 项因未设置独立 PostgreSQL 测试 DSN 而跳过；Ruff、前端构建与 OpenAPI 类型同步检查通过。PostgreSQL 游标路径已在隔离的本地实例单独验证。浏览器检查使用正在运行的隔离 Compose 实例 `127.0.0.1:8095`；主实例未修改。

**首版边界。** CPU/内存数字用于调度准入，并非强制资源上限。增量特征计算不意味着所有来源都只读取增量。向量特征、多节点恢复和完整多租户权限属于后续扩展。性能报告中的 Parquet 文件与产物大小不是执行器实际扫描字节数；当前报告不据此推断普遍加速比。
